# Security Policy

## Supported Versions

Security fixes are applied to the latest release on `main`.

| Version | Supported          |
|---------|--------------------|
| 2.0.x   | Yes                |
| < 2.0   | Best effort        |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report privately via either channel:

- **Email**: `167779155+DrSoma@users.noreply.github.com`
- **GitHub Security Advisories**: Use the "Report a vulnerability" button on the [Security Advisories page](https://github.com/DrSoma/PathSafe/security/advisories/new)

Include:

- Clear description of the issue
- Steps to reproduce
- Affected version(s)
- Potential impact
- Any suggested mitigation

## Response Timeline

- **Acknowledgment**: Within 48 hours of receiving the report
- **Initial assessment**: Within 7 days
- **Fix or mitigation**: Prioritized based on severity

## Coordinated Disclosure Policy

We follow a 90-day coordinated disclosure window. After a vulnerability is reported:

1. We will acknowledge receipt within 48 hours.
2. We will work with the reporter to validate and understand the issue.
3. We will develop and test a fix.
4. We will coordinate a public disclosure date, targeting no more than 90 days from the initial report.
5. The reporter will be credited in the advisory unless they prefer to remain anonymous.

If a fix cannot be completed within 90 days, we will negotiate an extended timeline with the reporter and provide an interim mitigation if possible.
